# Refactoring

## Workflow

1. Confirm the behavior to preserve.
2. Search all references before renaming classes, IDs, files, or functions.
3. Keep refactors separated from visual redesigns.
4. Validate all flows that share the edited component or asset.

## Quality Bar

- No config reference drift.
- No selector drift between HTML, CSS, and JavaScript.
- Generated output updates are intentional.
