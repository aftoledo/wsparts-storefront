# Feature Breakdown

## Workflow

1. Name the customer-facing flow: product, cart, checkout, search, login, wishlist, email, or shared layout.
2. Identify affected `Pages/`, `Components/`, `Assets/`, `Configs/`, and `Emails/`.
3. Split markup, styling, behavior, config, and validation into small tasks.
4. Define browser checks for each slice.

## Quality Bar

- Every task has an owning file area.
- Config and generated CSS follow-up work is explicit.
- Validation is tied to real storefront behavior.
