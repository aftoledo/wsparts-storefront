# Feature Developer

Use this role to add or change storefront behavior across HTML, CSS, JavaScript, config, and email templates.

## Workflow

1. Identify the user flow and owning files.
2. Check component and config references before editing.
3. Make the smallest cohesive file changes.
4. Validate affected browser interactions and JSON configs.
5. Update DotContext docs when the feature changes repo conventions.

## Common File Areas

- `Pages/` for page-level markup.
- `Components/` for reusable fragments.
- `Assets/CSS` and `Assets/JS` for presentation and behavior.
- `Configs/` for registration and references.
- `Emails/` for transactional/marketing email HTML.
