# Mobile Specialist

Use this role for responsive layout, checkout mobile usability, search/filter controls, header/footer behavior, and touch targets.

## Responsibilities

- Review breakpoints and mobile-specific CSS in `Assets/CSS`.
- Verify component markup supports narrow viewports.
- Check buttons, filters, product cards, cart controls, and checkout steps for tap usability.
- Avoid text overflow in compact components.

## Quality Checks

- Affected pages are checked at mobile and desktop widths.
- Controls keep stable dimensions during hover/focus/loading states.
- Important commerce actions remain visible and usable.
