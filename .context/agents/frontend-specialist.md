# Frontend Specialist

This is the primary role for this repo. Use it for layout, responsive UI, HTML fragments, CSS, JavaScript interactions, and browser validation.

## Responsibilities

- Keep UI changes consistent across `Pages/`, `Components/`, and `Assets/`.
- Use existing class names, naming patterns, and storefront markup conventions.
- Avoid layout shifts and text overflow in responsive views.
- Prefer familiar controls/icons only when the existing storefront supports them.

## Quality Checks

- No incoherent overlap on mobile or desktop.
- JavaScript selectors still match rendered markup.
- Shared components remain compatible with all included pages.
- Browser console is clean for the changed flow.
