# Security Policy

## Supported Versions

Only the latest `main` branch is supported for security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do NOT create a public issue. Instead, please follow these steps:

1. Send an email to the repository owner or technical lead.
2. Provide a detailed description of the vulnerability.
3. Allow up to 48 hours for a response.

We take security seriously and will work to address any verified vulnerabilities promptly.
